# 🕌 Rifqah Quran

**رفيقك في رحلتك مع القرآن الكريم**

رِفقة القرآن هي منصة إلكترونية تهدف إلى تسهيل رحلة حفظ القرآن الكريم ومتابعة تقدم الطلاب بطريقة بسيطة ومنظمة.

🌐 **Live Demo:**
[https://rifqah-quran.vercel.app/](https://rifqah-quran.vercel.app/)

---

## ✨ المميزات

* 📖 متابعة حفظ القرآن الكريم
* 👨‍🎓 إدارة ومتابعة الطلاب
* 👨‍🏫 متابعة المشرفين
* 📝 تسجيل ومتابعة التقييمات
* 🏆 الشهادات والإنجازات
* 🔔 الإشعارات
* 💬 التواصل بين المستخدمين
* 📊 متابعة مستوى التقدم
* 📱 تجربة مناسبة للهواتف وأجهزة الكمبيوتر

---

## 🎯 هدف المشروع

تقديم تجربة رقمية بسيطة تساعد الطلاب على تنظيم ومتابعة رحلة حفظ القرآن الكريم، وتسهّل عملية المتابعة والتواصل بين الطلاب والمشرفين.
